# Socially – Animated Landing Page Hero Section (HTML & CSS)

A modern, fully responsive **landing page hero section** for *Socially*, a social media platform concept — built using pure **HTML5 and CSS3** with smooth **CSS keyframe animations**. Perfect for developers learning how to build animated hero sections, gradient buttons, and responsive navbars for real-world landing pages.

## 🔍 About This Project

This **HTML CSS landing page** demonstrates how to build a modern **animated hero section** — the kind used on real SaaS, app, and social media websites. It covers essential front-end skills like responsive navbar design, gradient call-to-action buttons, hero image layering, and CSS `@keyframes` entrance animations. Great for beginners searching for a **landing page template**, **hero section tutorial**, or **CSS animation example** to learn from or customize.

## ✨ Features

- 🧭 Responsive navbar with logo, navigation links, login and CTA buttons
- 🖼️ Full-screen hero section with custom background image
- 🎨 Gradient "Join Now" and "Download App" buttons with smooth hover transitions
- ⬆️ Staggered fade-and-slide-up entrance animations using `@keyframes`
- 📱 Mobile-friendly, semantic HTML structure
- 🧩 Zero dependencies — no JavaScript, no frameworks

## 🛠️ Built With

- **HTML5** – semantic, accessible markup
- **CSS3** – Flexbox layout, gradients, transitions, `@keyframes` animation
- **Google Fonts** – Poppins typeface

## 🚀 Getting Started

### Prerequisites
No dependencies or build tools required — just a modern web browser.

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/socially-landing-page.git
   ```
2. Navigate to the project folder:
   ```bash
   cd socially-landing-page
   ```
3. Open `index.html` in your browser.

No `npm install`, no build step, no configuration needed.
